# Zenodo Archival Plan

Recommended archival sequence:

1. Rename the GitHub staging repository to `EGCP-External-Validation-UNSW-NB15`.
2. Verify repository contents and the `ARTIFACT_SHA256.txt` manifest.
3. Create GitHub release tag `v1.0.0` using `RELEASE_NOTES_v1.0.0.md`.
4. Connect the repository to Zenodo and archive the `v1.0.0` release, or upload the prepared release archive manually.
5. Record the minted DOI in `CITATION.cff`, `.zenodo.json`, README, and the journal manuscript Data/Code Availability statement.

Do not invent or pre-fill a DOI before Zenodo assigns or reserves one.
